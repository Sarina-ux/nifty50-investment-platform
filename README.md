# NIFTY-50 Investment Intelligence Platform

An AI-powered investment analytics platform built on historical NIFTY-50 market data (2000–2021).

## Features

- Stock Analysis — Candlestick charts, MACD, RSI, Bollinger Bands
- AI Predictor — XGBoost model predicting next-day price direction
- Portfolio Builder — Conservative, Balanced, Aggressive profiles
- Risk Assessment — Sharpe, Sortino, Max Drawdown, VaR, CVaR
- Anomaly Detection — Isolation Forest for unusual market events

## Dataset

- NIFTY-50 Stock Market Dataset (Kaggle): https://www.kaggle.com/datasets/rohanrao/nifty50-stock-market-data/data
- 50 companies, January 2000 – April 2021
- 470,000+ daily records

    pip install -r requirements.txt

    streamlit run app.py

Then open your browser at http://localhost:8501

## Reproducing Results

Run the following steps in exact order:

Step 1 — Download the dataset from Kaggle and place all CSV files inside the data/ folder.

Step 2 — Install dependencies:

    pip install -r requirements.txt

Step 3 — Run notebooks in this exact order inside the notebooks/ folder:

    01_EDA.ipynb               -> cleans data, saves cleaned_data.csv
    02_Stock_Predictor.ipynb   -> trains model, saves xgb_predictor.pkl and features_data.csv
    03_Portfolio_Risk.ipynb    -> builds portfolios, saves portfolios.csv and stock_metrics.csv
    04_Anomaly.ipynb           -> detects anomalies, saves anomaly_data.csv

Step 4 — Launch the dashboard:

    streamlit run app.py

Step 5 — Open browser at http://localhost:8501

Note: The data/ and models/ folders are not included in this repo due to file size limits.
All files are automatically generated by running the notebooks above in order.

- Algorithm: XGBoost Classifier
- Features: 20 technical indicators
- Train period: 2000-2019
- Test period: 2020-2021

## Anomaly Detection

- Algorithm: Isolation Forest (contamination = 2%)
- Anomalies found: 4,611 across all stocks
- Detects: Volatility spikes, volume spikes, extreme crashes and surges
- Correctly identifies 2008 crisis, COVID crash, Demonetisation
